The configuration page is specific for each user. The user can change and send one or more field at the same time, but all will be sent to the API endpoint. In there you can change:

# User properties

'user_id': int,

'username': str,

'first_name': str,

'last_name': str,

'email': str, // With email format validation

'is_active': bool, // Whether the user account is active

'is_staff': bool, // Whether the user can access the admin site

'is_superuser': bool, // Whether the user has all permissions without explicitly assigning them

'groups': list, // List of groups the user belongs to

'user_permissions': list // List of permissions assigned to the user

// Change password form (atomic operation)
